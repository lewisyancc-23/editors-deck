# 🚀 Getting Started

---

**1. Upload the Arduino firmware** 
Open the Arduino ``` .ino ``` file located in 
```text
hardware/
```

**2. Connect the Arduino**
Connect the Arduino UNO to your computer using USB.

**3. Install Python dependencies**
```text
pip install -r requirements.txt
```

**4. Run the Python controller**
```text
python main.py
```

**5. Open CapCut**
Once the controller is working, the physical controls can be used to interact with the editing workflow.
